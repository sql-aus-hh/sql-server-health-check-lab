# Workshop Scenarios

Hier entstehen die vier Szenarien aus dem SQLDays-Workshop.

Jedes Szenario soll nach der Aufbereitung möglichst dieselbe Struktur verwenden:

```text
README.md
Setup.sql
Validate.sql
Cleanup.sql
```

Die eigentliche Lösung wird bewusst getrennt unter `/solutions` dokumentiert, damit das Lab zunächst ohne Spoiler als Troubleshooting-Übung genutzt werden kann.
