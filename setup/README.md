# Common Setup

Dieser Ordner enthält den gemeinsamen Ausgangszustand für alle vier Workshop-Szenarien.

## Geplante Reihenfolge

1. `01-Common-Setup.sql`
2. `02-Validate-Setup.sql`

Das Common Setup wird so aufgebaut, dass jedes Szenario auf einem definierten und nachvollziehbaren Zustand beginnt.

## Noch offen

Die konkreten Voraussetzungen und Objekte werden ergänzt, sobald die originalen Workshop-Szenarien final rekonstruiert und bereinigt sind.
